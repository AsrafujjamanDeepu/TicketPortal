# TicketPortal

TicketPortal is a personal-project prototype for multi-operator bus search, booking, counter sales, operator tools, and platform finance. It uses a simulated payment flow; it does not connect to a real payment provider.

## Start here

- [Run the apps and test features by clicking through the UI](docs/01-Run-and-Manual-Test-Guide.md)
- [Project concept and solution](docs/02-Project-Concept-and-Solution.md)
- [Remaining fix plan for a future AI/developer pass](docs/03-Remaining-Fix-Plan.md)

The repository contains an Angular passenger/operator portal, a React admin console, an ASP.NET Core API, SQL Server EF migrations, LocalDB tests, and a mock ERP. See the run guide for prerequisites, commands, demo logins, and manual steps.
